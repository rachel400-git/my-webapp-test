# ⚡ DevPulse — מרכז הפיתוח והפרודוקטיביות (עברית & RTL)

אפליקציית רשת אינטראקטיבית, מודרנית ומעוצבת המיועדת למפתחים. האפליקציה תומכת באופן מלא בעברית ובכיווניות מימין-לשמאל (RTL), ללא צורך בספריות חיצוניות או שלב בנייה (Pure Vanilla JS, HTML5, CSS Variables).

---

## ✨ תכונות מרכזיות

- 📊 **לוח בקרה ומדדים**: גרף פעילות שבועי אינטראקטיבי מבוסס HTML5 Canvas, שעון חי, ציטוטי השראה יומיים ומדדי פרודוקטיביות בזמן אמת.
- 📋 **לוח משימות (קנבן)**: ניהול משימות אינטראקטיבי עם גרירה ושחרור (Drag & Drop), כפתורי קידום/החזרה, סינון לפי עדיפות, חיפוש ושמירה אוטומטית ב-`localStorage`.
- ⏱️ **טיימר ריכוז (פומודורו)**: מעגל התקדמות גרפי (SVG), מעבר בין סבבי עבודה להפסקות קצרות/ארוכות, וצליל מלודי נעים בסיום באמצעות ה-Web Audio API.
- 🛠️ **ארגז כלים למפתחים**:
  - **מעצב ומאמת JSON**: ייפוי, דחיסה ובדיקת תקינות תחביר.
  - **מקודד ומפענח Base64**: המרת מחרוזות טקסט (כולל עברית UTF-8).
  - **מחולל מזהי UUID v4**: יצירת מזהים תקניים עם העתקה בלחיצה אחת ללוח.
  - **מקודד ומפענח כתובות URL**: טיפול בטוח בפרמטרים וקישורים.
- 🎨 **גלריית פרויקטים**: תצוגת כרטיסי פרויקטים עם אפשרויות סינון לפי תחומים.
- 🌓 **מצב כהה ומצב בהיר**: כפתורי החלפה בולטים בכותרת העליונה ובסרגל הצד עם שמירת העדפה.

## 💻 הפעלה ובדיקה מקומית (Local Testing)

ניתן לפתוח את הקובץ `index.html` ישירות בדפדפן, או להפעיל שרת מקומי מהיר:

```powershell
# Python
python -m http.server 8080

# או פתיחה ישירה בדפדפן ברירת המחדל
Start-Process "index.html"
```
